# Mini Bowling

マウス操作で投球の方向・速さ・カーブを決める、Unity 6 製の1レーンボウリングゲームです。
10フレーム制と、ストライク／スペアを含む正式な得点計算に対応しています。

## ブラウザで遊ぶ

[Mini Bowlingをプレイする](https://kfugaku.github.io/bawling_game/)

インストールは不要です。マウスを使用するため、PCブラウザでのプレイを推奨します。
このページにはパスワード制限はありませんが、検索サイトなどへ積極的に公開せず、URLを共有した相手に遊んでもらう想定です。

## 操作方法

1. 右クリックを押し続けてボールを持ちます。
2. マウスを前へ動かして助走します。左右への動きで投球方向も細かく変わります。
3. 右クリックを離すと、その時点の助走量と速さでボールをリリースします。
4. リリース直前にマウスホイールを回すとカーブがかかります。回す方向でカーブ方向、速さで強さが変わります。
5. 投球とピンの動きが終わったら、`Space` キーで次の投球へ進みます。

## 実寸スケール

ゲーム内では、ボール直径 8.5 inch を `1 Unity unit` としています。レーン幅は 41.5 inch（約 `4.88 units`）、ファウルラインからヘッドピンまでは 60 ft（約 `84.71 units`）です。ピンは高さ 15 inch、最大幅 4.797 inch、ピン中心の間隔は 12 inch の比率で配置しています。

シーンを作り直すときは、Unityメニューの `Mini Bowling > Create Regulation Scene` を実行します。ピンの見た目はUSBCの高さごとの直径データから再生時に生成し、物理挙動用のコライダーとは分離しています。

## 開発・公開方法

- Unity: `6000.2.12f1`
- メインシーン: `Assets/Scenes/Bowling.unity`
- WebGLビルド: Unityメニューの `Mini Bowling > Build WebGL`
- 出力先: `docs/`

`docs/` の更新が対象ブランチへマージされると、GitHub ActionsがGitHub Pagesへ自動で公開します。
