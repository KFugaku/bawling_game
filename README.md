# Mini Bowling

Unity 6 で作る、1投でピンを倒すミニボウリングゲームです。

## 遊び方

- `←` / `→` : 球の狙いを左右に動かす
- `Space` : 投球
- `R` : ラウンドをやり直す

## 最初の完成目標

球を投げ、物理演算でピンを倒し、4秒後に倒した本数が画面に表示されます。

## 実寸スケール

ゲーム内では、ボール直径 8.5 inch を `1 Unity unit` としています。したがって、レーン幅は 41.5 inch（約 `4.88 units`）、ファウルラインからヘッドピンまでは 60 ft（約 `84.71 units`）です。ピンは高さ 15 inch、最大幅 4.797 inch、ピン中心の間隔は 12 inch の比率で配置しています。

シーンを作り直すときは、Unity メニューの `Mini Bowling > Create Regulation Scene` を実行します。これは現在のシーンを規格サイズのシーンに置き換えます。

ピンの見た目は、USBCの高さごとの直径データから再生時に生成しています。既存のカプセル型コライダーはそのまま使うため、見た目を改善しても投球時の物理挙動は安定します。
